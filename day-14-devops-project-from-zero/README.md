# Day 14 — DevOps Project from Absolute Zero

**Date:** 2026-07-26

## What I set out to learn

Build a simple DevOps project from scratch and understand how CI pipelines are implemented in Azure DevOps for an end-to-end workflow.

## What I did

- Set up a basic project structure for a simple application
- Learned how to create and organize a DevOps workflow from the beginning
- Explored the importance of version control, automation, and pipeline setup
- Implemented or reviewed the basic concepts of CI pipelines in Azure DevOps
- Connected the project flow from code commit to build/test automation

## What I learned / key takeaways

- A DevOps project can be started from absolute zero by defining the repository, workflow, and automation goals first
- CI pipelines help validate code automatically whenever changes are pushed
- Azure DevOps provides a structured way to run builds, tests, and quality checks consistently
- Early automation saves time and reduces manual errors in delivery processes
- A strong foundation in project setup makes later deployment and release processes easier
